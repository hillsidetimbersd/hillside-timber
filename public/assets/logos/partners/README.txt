PARTNER / SUPPLIER LOGOS  —  "Trusted Partners & Suppliers" strip on the home page
====================================================================================

These 8 files feed the scrolling logo strip. To swap any logo, drop a new file
in this folder using the SAME filename (and same extension) as below. The site
picks it up automatically. SVG is best (stays sharp at any size); a transparent
PNG at least 600px wide is the next best thing.

  ecopoxy.png          EcoPoxy            sharp, official color logo
  rubio-monocoat.png   Rubio Monocoat     sharp, official color logo
  wood-mizer.svg       Wood-Mizer         sharp vector
  general-finishes.png General Finishes   sharp, official crest
  festool.svg          Festool            sharp vector
  osmo.svg             Osmo               sharp vector
  totalboat.png        TotalBoat          *** LOW-RES (104x41) — replace if you
                                          can get a bigger/vector version ***
  timberking.svg       TimberKing         sharp vector, but it is an all-GOLD
                                          wordmark built for dark backgrounds, so
                                          it looks lighter than the rest on our
                                          light strip. A version with black/dark
                                          text would sit better. Replace if you
                                          have one.

If the better file you have is a DIFFERENT format than what's listed (e.g. a
TimberKing PNG instead of SVG), just drop it in and tell me the filename — I'll
point the strip at it. Don't rename a PNG to ".svg" (or vice-versa); the
extension has to match the real file type.
